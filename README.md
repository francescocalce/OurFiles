# OurFiles

Piattaforma web per la condivisione di appunti universitari tra colleghi di corso: caricamento, consultazione e ricerca dei materiali per materia o autore.

Progettata e sviluppata interamente in autonomia, ospitata su hosting Altervista e usata attivamente dai colleghi di corso.

## Funzionalità

- Login (gli account venivano creati direttamente da me per i colleghi di corso, nessuna registrazione autonoma)
- Caricamento di file (appunti, dispense) con associazione a materia e autore
- Consultazione e ricerca dei materiali caricati

## Tecnologie

- **Backend:** PHP, MySQL
- **Frontend:** HTML, CSS

## Nota

Il file `config.php` (credenziali del database) non è incluso nel repository per motivi di sicurezza.
